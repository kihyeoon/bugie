## 도구 요약

| 목적 | 도구 | 무료 한도 |
|------|------|----------|
| 행동 분석 | **PostHog** | 월 100만 이벤트 + 5,000 세션 리플레이 |
| 에러 수집 | **Sentry** | 월 5,000 에러 + 10,000 성능 단위 |

## 구현 순서

1. PostHog 설정 + 핵심 이벤트 추적 (~1주)
2. Sentry 설정 + ErrorBoundary + 서비스 에러 추적 (~3일)
3. 대시보드 구성 + 알림 설정 (~1일)
