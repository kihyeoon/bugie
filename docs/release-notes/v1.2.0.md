# v1.2.0 릴리즈 노트

## 출시일
2026-04-05

## 새 기능

### 결제 수단 관리
거래 입력 시 **결제 수단(카드, 현금, 계좌이체 등)**을 선택할 수 있습니다.
- 결제 수단 추가/수정/삭제 지원
- 빠른 입력 및 거래 상세에서 결제 수단 선택 가능
- 카테고리와 동일한 컨텍스트 메뉴(롱프레스) 방식으로 관리

### 빠른입력 날짜 UX 개선
- 홈 캘린더에서 선택한 날짜가 빠른입력에 자동 반영
- 날짜 선택 범위를 1년 후까지 확장

## 버그 수정

- 서드파티 키보드 사용 중 백그라운드 복귀 시 화이트스크린 발생하는 문제 수정
- 거래 상세에서 카테고리 수정/삭제 시 사일런트 실패하는 문제 수정
- Auth 초기화 실패 시 스플래시 화면에서 무한 대기하는 문제 수정
- 빠른입력 탭 복귀 시 카테고리/결제수단 목록이 갱신되지 않는 문제 수정
- 카테고리 컨텍스트 메뉴 아이콘이 올바르게 표시되지 않는 문제 수정
- 카테고리/결제수단 컨텍스트 메뉴와 모달이 중첩되는 문제 수정
- 결제 수단 CRUD 동작 일관성 수정
- 회원 탈퇴 처리 함수(force_clean_user) 버그 수정
