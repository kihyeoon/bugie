## 버그 수정

### 화면 전환 시 헤더 깜빡임 제거
- 거래 목록·거래 상세·가계부 관리·가계부 설정·프로필 설정·결제 수단 관리 화면에 진입할 때,
  기본 헤더가 한 프레임 스쳐 지나간 뒤 화면 내용이 아래에서 위로 밀려 올라오던 문제 수정
- 원인: 스택 화면이 루트 레이아웃에 선언되지 않아 첫 렌더에서 기본 옵션(헤더 표시)이 적용되고,
  화면 본문의 `Stack.Screen`이 한 커밋 늦게 `headerShown: false`를 적용하면서
  `UINavigationBar`가 생성됐다가 애니메이션으로 사라짐
- 수정: 루트 `Stack`의 `screenOptions`에서 헤더를 처음부터 끄도록 변경
