## 버그 수정

### 뒤로가기를 빠르게 두 번 할 때 이전 화면이 되돌아오던 문제 수정

- 거래 상세에서 뒤로 스와이프를 빠르게 두 번 하면, 홈에 도착한 뒤 거래 목록이
  다시 밀려 들어왔다가 사라지던 문제 수정 (`A → B → C → B → A → B → A`)
- 원인: `react-native-screens`의 레이스 컨디션. 네이티브가 이미 dismiss한 화면을
  뒤늦게 도착한 JS 상태 업데이트가 다시 붙였다(reattach).
  `RNSScreenStack.mm`이 JS 라우트에는 있고 네이티브에는 없는 화면을
  `pushViewController:animated:YES`로 되돌려 넣는 경로
- 수정: `react-native-screens` 4.11.1 → 4.26.2. 수정은 PR
  [#3584](https://github.com/software-mansion/react-native-screens/pull/3584)에 들어 있고,
  플래그 `iosPreventReattachmentOfDismissedScreens`가 4.24.0부터 기본 활성이다
  (이슈 [#2559](https://github.com/software-mansion/react-native-screens/issues/2559))
- **이 수정을 적용하려면 Expo SDK 업그레이드가 필요했다.** 수정이 포함된 rns는
  RN 0.80+ 전용이라(스펙 파일이 `CodegenTypes` 네임스페이스 export를 사용) SDK 53(RN 0.79)에서는
  라이브러리만 올리는 방법이 존재하지 않았다

## 마이그레이션

코드 변경이 필요했던 항목들. 앞으로 이 저장소에서 지켜야 할 규약이기도 하다.

- **`@react-navigation/*`를 직접 import하지 않는다.** SDK 56부터 expo-router가
  React Navigation 의존을 끊었다. `expo-router/react-navigation`(테마, `useFocusEffect`,
  `PlatformPressable`)과 `expo-router/js-tabs`(`BottomTabBarButtonProps`,
  `useBottomTabBarHeight`)를 쓴다. 패키지 3개는 제거됨
- **reanimated 4**: `runOnJS(fn)(arg)` → `react-native-worklets`의 `scheduleOnRN(fn, arg)`.
  `AnimatedStyleProp` → `AnimatedStyle`
- **`useColorScheme`은 `'light' | 'dark'`를 반환한다.** RN 0.86의 `ColorSchemeName`에
  `'unspecified'`가 추가돼 `Colors[...]` 인덱싱이 전부 깨졌다. hook에서 좁혀 반환하도록 고쳤다
- **`StyleSheet.absoluteFillObject` → `StyleSheet.absoluteFill`.** RN 0.86에서 전자의
  타입이 제거됐고, 후자가 동일한 평범한 객체라 spread 동작은 같다
- `@repo/ui`의 `react`/`react-native`를 `peerDependencies`로 이동.
  `dependencies`로 두면 중복 네이티브 모듈이 설치된다
