## 새 기능

### 가입할 때 닉네임을 정한다 (BGI-40)

- **왜**: 닉네임 화면이 사실상 뜨지 않았다. 앱이 "이름이 있는가"로 판정했는데, 애플 가입자는 이름이
  이메일 앞부분(Private Relay라 `vtnh59jpv9` 같은 무작위 문자열)으로 채워져 판정을 통과했다.
  2026-09-23 실측으로 **애플 28명 중 13명**이 이 이름 그대로였고(나머지는 나중에 직접 수정),
  첫 가계부도 "vtnh59jpv9의 가계부"로 만들어져 공유 상대와 초대 메시지에 그대로 보였다
- 애플 로그인을 도입한 2025-10-21부터 애플 이름이 한 번도 저장되지 않았다
- 원인은 둘이었다. 애플은 첫 승인 때만 이름을 주는데, 로그인 중 프로필이 이름 없이 먼저 만들어졌다.
  그리고 판정이 이름의 모양에 기대고 있었다
- **`profiles.onboarded_at`**으로 "사용자가 직접 정했는가"를 기록하고, null이면 닉네임 화면을 한 번 보여준다
- 애플 이름은 로그인 전에 넘겨 프로필 생성에 쓰이게 했다. 구글은 구글 이름이 기본값으로 채워진다
- 닉네임을 저장하면 **기본 가계부 이름도 함께 바꾼다**(내가 만든 "{옛 이름}의 가계부"만. 다른 가계부는 그대로)
- "다른 계정으로 로그인"으로 잘못 가입한 계정에서 빠져나갈 수 있다. 건너뛰기는 없다
- 초대 링크로 가입하면 닉네임을 정한 뒤 초대 수락 화면으로 이어진다

설계 문서: `docs/features/signup-nickname/design.md`

## 개선

### 화면을 오갈 때 로딩 깜빡임 제거 (BGI-33)

- 화면에 들어올 때마다 빈 화면과 스피너를 거쳐 다시 받았다
- TanStack Query 캐시를 도입해 **이전 데이터를 먼저 보여주고 뒤에서 갱신한다**.
  홈·거래 목록·거래 상세·카테고리·결제 수단이 대상
- 홈은 앞뒤 달을 미리 받아 둔다. 월을 넘길 때 이전 달 합계가 잠깐 보이던 문제도 함께 해결
- 공유 가계부라 상대방 입력이 보여야 해서, 화면에 들어올 때마다 재조회는 그대로 한다

### 거래 상세 화면 정리 (BGI-20)

- 항목 라벨과 값이 겹치던 문제 수정. 정보 행 7개를 `TransactionInfoRow` 하나로 통합
- 긴 값은 한 줄 말줄임. 메모는 한 줄에 들어가면 인라인, 넘치면 라벨 아래 펼쳐 전문을 보여준다

### 더보기 화면의 버전 표시

- `버전 1.0.0`으로 하드코딩돼 있던 것을 `app.json`의 버전으로 표시한다

### 빠른입력 카테고리 스피너 제거 (빌드 25)

- 빠른입력에 처음 들어가면 카테고리 선택칸이 스피너로 바뀌고 눌리지 않았다. 금액을 먼저 입력하므로
  선택칸을 누를 때쯤이면 이미 받아져 있어 불필요한 로딩이었다
- 선택칸은 로딩 중에도 그대로 둔다. 그 전에 누르면 바텀시트 안에서만 로딩을 보여준다
- 홈 첫 화면이 뜬 뒤 카테고리를 미리 받아 둔다(`usePrefetchCategories`). 빠른입력·거래 상세가 캐시에서 바로 뜬다

### 다크모드 색상 정리 (빌드 25)

- 거래 상세의 섹션 사이 배경이 라이트 회색(`#F2F4F6`)으로 하드코딩돼 다크모드에서 밝은 띠로 보였다
  → `colors.backgroundSecondary`
- 같은 종류: 카테고리 추가 모달 헤더 구분선, 결제 수단 모달 스위치의 꺼짐 트랙
- 나머지 다크모드 점검은 BGI-49
