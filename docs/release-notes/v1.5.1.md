## 새 기능

### 새 버전 안내 (BGI-52)

- **왜**: 1.5.0까지는 앱 안에서 업데이트를 알릴 방법이 없었다. 이 기능은 **코드가 들어간 버전부터만 효과**가 나서
  호환이 깨지는 변경이 필요해지기 전에 미리 깔아 둔다
- Supabase `app_versions`의 플랫폼별 행을 앱이 켤 때와 백그라운드에서 돌아올 때 읽는다
  - `min_supported_version`보다 낮으면 전체 화면으로 막고 App Store로 보낸다(강제). 로그인 전·딥링크 진입에서도 막는다
  - `recommended_version`보다 낮으면 홈에서 Alert를 버전당 한 번 띄운다(권장). **평소엔 비워 두고** 알리고 싶은 기능을 냈을 때만 넣는다
- 값을 읽지 못하면(네트워크 오류 등) 그냥 통과한다
- 운영법과 주의점: `docs/guide/app-version-policy.md`

## 개선

### 거래 없는 달에도 거래 목록 캘린더 유지 (BGI-39)

- 거래가 없는 달·로딩 중·에러일 때 캘린더까지 빈 화면으로 바뀌어, 월을 넘길 때 캘린더가 사라졌다 나타났다
- 목록 자리만 빈 상태로 바꾸고 캘린더는 그대로 둔다. 빈 달엔 합계 푸터를 숨긴다
- 이 변경으로 드러난 "월 전환 직후 예약된 날짜 스크롤이 빈 목록에서 실행돼 크래시"도 함께 막았다(출시본엔 없던 문제)

## 버그 수정

### 날짜 문자열을 로컬 자정으로 파싱 (BGI-34)

- `new Date('YYYY-MM-DD')`는 UTC 자정이라 음수 오프셋 시간대(미주 등)에서 하루 전으로 밀린다
- 거래 저장·수정·조회 필터와 거래 목록·상세, 날짜 포맷터를 `parseLocalDate`로 통일. 한국 시간대 사용자는 체감 변화 없음

## 제출할 때

- **App Store 기본 언어를 영어 → 한국어로 바꾸고 영어 현지화는 삭제했다** (2026-09-26, 이번 제출과 함께).
  1.5.0 출시 뒤엔 "각 버전 한국어 스크린샷 필요" 오류로 바꿀 수 없었다
