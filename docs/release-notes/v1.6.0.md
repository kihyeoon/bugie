## 새 기능

### 거래 검색 (BGI-45)

- **왜**: 지난 거래를 찾으려면 캘린더로 달을 넘겨 보는 수밖에 없었다
- 홈 헤더(가계부 이름 줄) 오른쪽 🔍 → 검색 화면. 현재 가계부의 **전체 기간**에서 제목·메모를 부분 일치로 찾는다(대소문자 무시)
- 결과는 날짜별로 묶고, 올해가 아닌 날짜엔 연도를 붙인다. 메모에서만 걸린 거래는 두 번째 줄에 `메모 · …스니펫`
- 입력을 멈추고 0.3초 뒤 검색, 키보드 검색 키를 누르면 바로. 끝에 붙은 조합 중 낱자("김ㅂ")는 떼고 찾는다
- 결과는 한 번에 받는다(상한 1,000건. 가장 큰 가계부가 401건)
- 설계: `docs/features/search/design.md`. 초성 검색은 후속(BGI-54)

### 거래 목록 멤버 필터 (BGI-43)

- **왜**: 공유 가계부에서 개인 지출을 따로 볼 수 없었다
- 거래 목록 헤더 오른쪽(월 표시 오른쪽) 알약을 누르면 멤버 선택 시트. 목록·캘린더 일별 합계·월 합계가 같은 기준으로 바뀐다
- "누구의 거래" = 지출한 사람, 없으면 작성자(`coalesce(paid_by, created_by)`)
- 멤버가 한 명인 가계부에는 필터가 없다. 홈 화면에는 적용하지 않는다
- 설계: `docs/features/member-filter/design.md`

## 개선

- 수입 거래의 "지출자" 라벨을 **"받은 사람"**으로, 지출은 **"지출한 사람"**으로 바꿨다 (빠른 입력·거래 상세, BGI-43)
- 멤버를 바꿀 때 캘린더 금액이 사라졌다 나타나지 않는다 (BGI-43)

## 내부

- 거래 상세가 목록·검색 캐시에서 거래를 찾을 때 배열이 아닌 캐시는 건너뛴다(크래시 방지)
- 거래 목록 날짜 헤더(`DateSectionHeader`)와 날짜별 묶기(`groupByDate`)를 검색과 공용으로 분리
- `@repo/core`에 검색어 정리·메모 스니펫 규칙과 테스트 추가

## 출시 전 확인 (TestFlight)

**거래 검색 (BGI-45)** — 시뮬레이터에서 검색·메모 스니펫·연도·수정/삭제 반영·다크 모드는 확인함. 실기기에서만 볼 수 있는 것 위주
- [ ] 홈 🔍 → 검색 화면이 열리며 키보드가 바로 올라온다. 이때 화면 전환이 버벅이지 않는다
- [ ] 한글 키보드로 빠르게 쳐도 자모가 갈라지지 않는다("김밥"이 "김ㅂ밥" 등으로 깨지지 않음)
- [ ] "김ㅂ"에서 멈추면 "김"의 결과가 보인다
- [ ] 키보드가 떠 있는 채 뒤로 스와이프하면 키보드가 내려간다
- [ ] 결과를 눌러 상세로 가면 키보드가 없고, 돌아오면 검색어·스크롤이 그대로
- [ ] 상세에서 제목 수정·삭제 후 돌아오면 반영된다
- [ ] 다크 모드에서 입력 글자·커서가 보인다

**멤버 필터 (BGI-43)** — 공유 가계부로
- [ ] 거래 목록 헤더에 월이 가운데, 필터 알약이 오른쪽
- [ ] 멤버를 바꾸면 목록·캘린더·월 합계가 함께 바뀌고, 캘린더 금액이 깜빡이지 않는다
- [ ] 개인 가계부(멤버 1명)엔 필터가 없다
- [ ] 홈 합계는 필터와 무관하게 가계부 전체

**기본 회귀**
- [ ] 더보기에 `버전 1.6.0`
- [ ] 거래 추가·수정·삭제 후 홈 합계와 목록에 반영
- [ ] 수입 입력·상세에 "받은 사람", 지출엔 "지출한 사람"
